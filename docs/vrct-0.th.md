# คู่มือ VRCT-0

[English](vrct-0.md) · [เอกสารทั้งหมด](README.md)

VRCT-0 พัฒนาต่อจาก VRCT พร้อมชื่อ โลโก้ และไอคอนใหม่ โดยคงเครดิตผู้พัฒนาเดิมไว้

## สิ่งที่เปลี่ยนใน fork นี้

VRCT-0 เป็น fork ของ [VRCT](https://github.com/misyaguziya/VRCT) โดยคงรูปแบบการแปลและถอดเสียงไว้ และปรับส่วนต่อไปนี้:

- **Backend Rust:** แทน Python sidecar และ runtime ที่เคยรวมในแอป รวมการตั้งค่า ผู้ให้บริการแปล โมเดล OSC และโอเวอร์เลย์ไว้ในระบบ native
- **ระบบเสียง Windows:** เลือก Host/Device แยกสำหรับไมโครโฟนและลำโพง รองรับแหล่งเสียง WASAPI, playback loopback, ASIO และแผงตั้งค่าไดรเวอร์
- **เครื่องมือ native:** จับภาพ จัดเตรียม dataset ทำ annotation ฝึกและส่งออกโมเดลตรวจจับ รวมถึงประเมินการถอดเสียง
- **แบรนด์:** ชื่อ VRCT-0 ไอคอนใหม่ และโลโก้สำหรับพื้นหลังสว่างและมืด
- **รูปลักษณ์:** ธีมมืด สว่าง และตามระบบที่บันทึกตัวเลือกได้ พร้อมปรับปรุงคำแปลหน้าจอ
- **บิลด์และแจกจ่าย:** ใช้ Rust xtask เตรียมทรัพยากรและตรวจแพ็กเกจ อัปเดตจาก Releases ของ fork นี้ และไม่แจกโมเดลตรวจจับกล่องแชตเดิมที่มีข้อจำกัดด้านสิทธิ์

ดู [native backend](native_pipeline.md), [ระบบเสียง](windows_audio.md) และ [native tools](native_tools.md) สำหรับรายละเอียด

## ภาษาหน้าจอ

เปิด **การตั้งค่า → รูปลักษณ์ → ภาษาหน้าจอ** แล้วเลือกภาษาที่ต้องการ ภาษาเปลี่ยนทันทีและบันทึกใน `config.json` สามารถเลือกภาษาตั้งแต่ติดตั้งได้เช่นกัน

ภาษาหน้าจอแยกจากภาษาสำหรับแปล ถอดเสียง และ OCR จึงต้องเลือกภาษาสำหรับแต่ละฟีเจอร์เอง ความสามารถขึ้นอยู่กับโมเดลหรือผู้ให้บริการที่ใช้

## เปลี่ยนธีม

เปิด **การตั้งค่า → รูปลักษณ์ → ธีม** แล้วเลือก:

- **มืด**: พื้นหลังมืด ตัวอักษรสว่าง
- **สว่าง**: พื้นหลังสว่าง ตัวอักษรเข้ม
- **ตามระบบ**: เปลี่ยนตามธีม Windows โดยอัตโนมัติ รวมถึงขณะเปิดแอปอยู่

ค่าเริ่มต้นคือ **ตามระบบ** แอปบันทึกธีมในพื้นที่เก็บข้อมูลของ WebView บนเครื่องนี้ด้วยคีย์ `vrct-0.theme` แยกจาก `config.json` หากล้างข้อมูล WebView ธีมจะกลับเป็นตามระบบ หากบันทึกข้อมูลไม่ได้จะใช้ตัวเลือกได้เฉพาะรอบที่เปิดอยู่

ธีมนี้ใช้กับหน้าต่างแอป ส่วนโอเวอร์เลย์ VR และ OBS ใช้การตั้งค่าของตนเอง

## ดาวน์โหลดและสร้างแอป

ดาวน์โหลดจาก [Releases ของ LogicCuteGuy](https://github.com/LogicCuteGuy/VRCT-0/releases) แตกไฟล์ทั้งหมดก่อนเปิดแอป ไฟล์ `VRCT.exe` และ `VRCT.zip` ยังคงชื่อเดิมเพื่อรองรับระบบแพ็กเกจ แต่ชื่อที่แสดงคือ VRCT-0

ดู [วิธีบิลด์](readme_build.md) และ [ข้อกำหนดระบบเสียง Windows](windows_audio.md) สำหรับการพัฒนา ระบบ ASIO ต้องใช้ libclang

```powershell
npm ci
npm run test:appearance
npm run vite-build
```
